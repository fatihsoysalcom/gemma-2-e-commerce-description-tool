# Gemma 2 E-commerce Description Tool

This example demonstrates how to integrate Google's Gemma 2 language model (accessed via the Gemini API) to generate product descriptions for e-commerce listings. It simulates the core functionality of the CraftList AI studio, focusing on creating attractive and informative descriptions for local businesses based on product name, category, and features.

## Language

`python`

## How to Run

1. Install the Google Generative AI library: `pip install google-generativeai`
2. Obtain an API key from Google AI Studio (https://aistudio.google.com/app/apikey).
3. Set your API key as an environment variable: `export GEMINI_API_KEY='YOUR_API_KEY'` (Linux/macOS) or `$env:GEMINI_API_KEY='YOUR_API_KEY'` (PowerShell).
4. Run the script: `python main.py`
